Turmeric Arcade

Spices

Ticking a spice declares it in the program's defscript header, so the program runs the same with tur --enable=script-deps. Imports work without it.

Turmeric Arcade runs programs on an engine that needs JavaScript Promise Integration (JSPI), which this browser does not have. Chrome and Edge 137 or later have it today; Firefox and Safari have it on the way. You can still read, edit and share programs here.
